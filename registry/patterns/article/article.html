The selector is the documentation

What changed when we stopped naming things twice — once in the markup and once in a stylesheet nobody could read — and let five attributes carry the whole interface.

AO Ada Okafor 14 September 2026 · 7 min read

Every team we talked to had the same stylesheet: four thousand lines of utility classes, a naming convention three people remembered, and a rule somewhere near the bottom that nobody dared delete. The markup that used it was unreadable in the honest sense — you could not tell what a block was for without opening the sheet beside it.

So we tried the opposite. A component is a data-ui, its children are data-parts, and anything that changes how it looks or what it is doing is a data-variant, a data-size or a data-state. Five attributes. Nothing else is allowed to carry meaning.

What the constraint bought us

The first thing it bought was a reader that is not a person. A manifest can say which parts a component has and which variants it accepts, and a linter can check a page against that in a few milliseconds — not by guessing at class names, but by reading the same attributes the stylesheet reads.

The second thing was cheaper than we expected: the stylesheet shrank. When a selector is the attribute it styles, there is nowhere for a dead rule to hide, and every part of every component is listed in one place that the audit keeps honest.

Shipping a theme without touching a component

Six axes, one seed, and the tokens that let a serif editorial theme and a flat dashboard theme share every line of component CSS.

MR Mateo Rossi 2 August 2026 · 11 min read

A theme used to be a fork. You copied the stylesheet, changed the colours, and from that day on every fix upstream was a merge conflict waiting for you. The tokens changed that in a way the colours alone never could, because the things a theme wants to say are not colours.

The six axes

Type, shape, depth, material, motion and density. Each axis is a handful of tokens a theme re-points, and each token has exactly one job: the heading face, the corner shape, how far a card rises under the pointer. A theme is a short file of opinions, not a second copy of the registry.

Type and shape

The heading voice is four tokens — face, weight, tracking and leading — and every heading in the registry reads them. Swap the face for a serif and the hero, the cards and the dialog titles follow, with nothing to chase.

Motion is a token too

How content arrives is one family: a distance, a duration, an easing and a stagger. A brisk theme shortens all four; a theatrical one lengthens them. And because reduced motion is honoured by every component that moves, a theme never has to think about it.

Release notes, written for the reader

PN Priya Nair 20 June 2026 · 3 min read

A changelog is read by someone who has one question: does this break me? We now answer that in the first line of every entry, before the list of what changed, and we say it in the words of the thing that broke — the attribute, the part, the token — not the task number that moved it.

The migration gate reads the same file, so an entry that forgets to say so does not ship.
