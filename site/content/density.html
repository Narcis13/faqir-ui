Density

One sanctioned axis for how tightly a subtree renders.

Put data-density="compact" on any container to tighten its spacing and control tokens. The attribute is a pure-CSS protocol modifier, not a sixth component attribute: it identifies no component and no controller reads it.

The axis

Compact where information density earns it.

Tables, forms, and toolbars may opt into compact density. Comfortable is the base scale and is also an explicit reset value for nested subtrees.

Nesting and reset

The nearest density scope wins.

Compact applies to the element itself and every descendant. An inner data-density="comfortable" re-declares the base values, so that subtree resets honestly instead of inheriting the compact result.

Complete remap

Nothing density-aware is implicit.

Spacing rungs --space-0h through --space-64 scale by 0.75 in compact mode; controls use the explicit 28/32/40px compact ramp. --space-0 and --space-px stay invariant. Every alias below is re-declared so it re-substitutes in the nearest density scope.

The page-rhythm aliases are part of that contract: --section-gap-sm, --section-gap-md, --section-gap-lg, and --content-gutter all remap. Paged-media --doc-* and --page-* tokens do not.
