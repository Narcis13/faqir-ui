A design system that explains itself.

Every choice in Faqir reduces ambiguity for the next human or machine that touches the interface.

  • Manifest-driven

    Anatomy, slots, variants, states, accessibility, tokens, and safe transforms live beside every component.

  • Auditable by design

    The CLI, browser playground, and MCP server run the same deterministic rules and can repair safe violations.

  • Framework optional

    Use plain HTML, the reactive engine, React, Vue, or server templates. The DOM contract stays exactly the same.

Two-minute start

Own the code. Keep the contract.

Install the CLI, choose a theme, and add only what the interface needs.

npm install -g faqir-ui-cli
faqir init --theme aurora
faqir add button card dialog grid
faqir dev

Your project receives plain HTML, CSS, manifests, controllers, and a generated context file for the next agent.
