faqir-tweak

The theme studio: turn a dial, and every component follows.

One element, <aside l-tweak>, mounts dials for scheme, density, accent, shape, type, motion and material. Each dial writes design tokens onto <html> as inline custom properties. Nothing is recompiled, and Copy CSS hands the result back as a :root block to paste into a theme. Pick a starting theme in the header first; the dials scale what that theme declares.

In your own page

Two script tags and one element.

The plugin is one self-registering file with no dependencies. Its state persists in localStorage, so a tweak survives a reload; take it out of the page and the theme is exactly what it was. 

<script src="core/faqir-core.js" defer></script>
<script src="core/plugins/faqir-tweak.js" defer></script>

<aside l-tweak aria-label="Theme studio"></aside>

From script

  • Faqir.tweak.css() returns the overrides as a :root block.
  • Faqir.tweak.apply(state) sets dials programmatically.
  • Faqir.tweak.reset() goes back to the theme.
  • Faqir.tweak.restore() re-applies the saved state.
  • Faqir.tweak.state is the current dial values.
