Named pages: the paper comes from the document.

A document asks for its own @page by name, so an app that bundles the pattern but prints an ordinary page keeps the browser's margins. A document that states both its format and its orientation pins a literal page, so one file can print an A4 invoice and a Letter statement.

A change of named page is a forced break, so only documents that ask for different paper break between them. The page counter reads Page 1 / 3 and is localised from the document's lang for German, Spanish, French, Italian, Dutch, Portuguese and Romanian; any other language sets --doc-page-label, --doc-page-separator and --doc-page-suffix on :root.

Running headers and footers, two ways.

By default the document's own doc-header and doc-footer repeat on every printed page. Two attributes change that, and both are opt-in.

data-header="from-page-2"

Leaves the running header off the first page, where the letterhead already is.

data-running="margin"

Prints the header and footer from two CSS strings in the page-margin boxes, with the footer and the counter on one line under one rule. The DOM header stays for the screen.

:root {
  --doc-running-header: "Forecraft · Quarterly report";
  --doc-running-footer: "Confidential \A Registered in Bucharest";
}

Set the strings on :root: a page box inherits from the root element only.

A business letter that fits the envelope.

data-variant="letter" is a DIN 5008 letter: A4, fold marks at 105 and 210 mm, a punch mark at 148.5 mm, and an address part that prints inside the Form B window. data-form="a" moves it to Form A. 

<article data-ui="document" data-variant="letter" lang="de" aria-label="Letter to Müller GmbH">
  <header data-part="doc-header"> … letterhead … </header>
  <address data-part="address">Müller GmbH<br>Hauptstraße 5<br>10115 Berlin</address>
  <div data-part="body"> … </div>
</article>

Every component with data prints its data.

The chart below is drawn by faqir-chart.js from its own table. On screen the table is visually hidden and a screen reader still reaches it; on paper it prints under the drawing. Print this page to see both.

  • table repeats its head on every page, and data-print-footer="last" prints the totals row once, at the end.
  • qr-code encodes versions 1 to 40 and barcode draws its bars; both keep a quiet zone (--qr-quiet, --barcode-quiet) and set data-state="error" on a value they cannot encode.
  • quote takes data-mark="above|hang|none" and sizes itself from the document it sits in; page-break forces a break before or after itself, and shows where on screen.
  • faqir fonts add <family> --italic installs the true italics thirteen catalog families ship, pinned by SHA-256, so emphasis on paper is a real italic rather than a slanted roman.

Five print themes, five voices.

A print theme used to differ from another only in hue. Now each one re-declares the document tokens that make a table read differently on paper: how heavy the rules are, how large the numerals sit and whether the first and last cells hang flush. A muted value below is the token layer's default, kept by that theme.

faqir theme generate with document: true gives a seed's print companion the voice of its type.pairing: a serif pairing prints like editorial-document, sans-grotesque like swiss-document, and slab like ink-document.
