Spacing & rhythm

Choose by relationship, not by whichever number looks close.

Use --space-* inside a component or an intentional group. Use --section-gap-* for page-level air. For an ordinary sequence of block components, choose nothing: the default rhythm already separates them.

The complete ladder

One scale, five bands.

Values are shown in rem in the source-of-truth column and in pixels only as a comparison at the default 16px root. Density remaps the rem-based rungs; it never changes zero or a one-pixel hairline.

Page-level aliases

Name the role of the air.

Pick a section token by intent—dense, marketing, or spacious—not by reverse-engineering its current value. The aliases compose spacing rungs, so compact density remaps them in the same scope.

The default rule

A bare sequence is already spaced.

Inside a flow root, consecutive block-level Faqir components and nested flow roots are separated by --flow-space. It defaults to --section-gap-sm. Add a stack only when you need a different direction, alignment, or deliberate local rhythm.

This is the 0.9-07 pair: each field-group owns its tight --space-* label → control → help step; the surrounding form owns the looser sibling-field step through the default rhythm. Neither duplicates the other.

Override deliberately

Re-tune at the owning flow root.

Put data-gap on the flow root when the whole sequence needs a different local cadence. data-gap="0" disables the inherited rhythm. Do not add sibling margins to each component.
